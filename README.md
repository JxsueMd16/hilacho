# Hilacho 🧶

Juego de plataformas 2D hecho para el reto **open2 — Build & Pitch**.

Eres Hilacho, un gato pequeño con su hilo de lana. Lanza hilo que se convierte en
plataforma: puentes sobre el agua, rampas para subir muros y arcos que bajan hasta
repisas lejanas. Enreda ratones, cuídate de las polillas (¡se comen tu hilo!) y llega
a la caja lo más rápido posible.

## Controles

| Tecla | Acción |
|---|---|
| ← → / A D | Caminar |
| Espacio / W / ↑ | Saltar (mantén para más altura) |
| Shift / J (mantener) | Lanzar hilo |
| ↑ / ↓ mientras lanzas | Estirar / bajar el arco |
| →→ / ←← | Dash |
| ↓ / S en el aire | Caer rápido |
| R | Reintentar nivel |
| Esc / P | Pausa |

## Reglas del reto

- Un solo `index.html`, menos de 32 KB sin comprimir.
- Canvas + JavaScript vanilla: sin librerías, frameworks ni motores.
- Cero assets: todo se dibuja y suena con código (la música de marimba se sintetiza con Web Audio).
